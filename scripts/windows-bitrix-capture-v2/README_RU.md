# AEROVENTA — оригиналы старого Bitrix (Windows one-click V2)

1. Распакуйте ZIP в отдельную папку на Windows.
2. Дважды нажмите `START_CAPTURE_BITRIX.cmd`.
3. После сообщения `Attach ZIP` отправьте в ChatGPT **`AEROVENTA_BITRIX_PUBLIC_RETURN_*.zip`**.

**Почему V2:** в первой попытке все 29 HTML и PDF не были получены по сети; завершение дополнительно ломалось при построении отчёта (`Типы аргумента не совпадают`). V2 использует встроенный Windows `curl.exe` вместо прежнего .NET `GetResult()`, исправляет структуру отчёта и всегда пытается создать RETURN ZIP. Сначала делаются только два ограниченных запроса на корневую страницу; при недоступном сайте остальные 29 запросов **не выполняются**.

При успешном соединении скачиваются исходные HTML 29 публичных страниц, ссылки на фото и схемы внутри `/upload/`, обязательный PDF. Имена файлов URL сохраняются в отчёте, SHA256 указывает на точные полученные байты. Максимум 400 медиа, 12 MiB на один медиафайл, 3 MiB на HTML; каждый запрос ограничен 18 секундами. Данные не загружаются в сторонний сервис. Никакой авторизации, SQL, изменений сервера, production/staging и доступа к личным файлам нет.

Если браузер открывает сайт, а `curl.exe` — нет, **не надо вручную искать и менять VPN/сервер**. Приложите диагностический RETURN ZIP: по коду ошибки будет выбрано одно безопасное исправление. Возможные причины — прокси, DNS, TLS или временная недоступность хостинга; без фактического кода curl не делается вывод о причине.

Это копия **текущего публичного сайта**, не гарантированно побайтовый исходник августовского 17-part Bitrix backup. Полная SEO-преемственность проверяется отдельно, публикация остаётся заблокированной до доказательства.
